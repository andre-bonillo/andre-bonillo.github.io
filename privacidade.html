Política de privacidade

Claude e-mail é uma ferramenta pessoal, de uso privado, usada apenas nas contas de e-mail do seu titular. Não é um produto da Anthropic, OpenAI ou Google. Esta política descreve como a ferramenta acessa, usa, armazena e compartilha os dados das contas Google autorizadas.

Dados acessados

  • As mensagens das caixas de e-mail do titular (cabeçalhos, texto e anexos), pelo protocolo IMAP, com o escopo do Gmail concedido no login do Google.
  • O endereço de e-mail da conta, usado só para conferir que a conta autorizada é a esperada.

Como os dados são usados

Só para o titular ler, buscar e organizar as próprias mensagens. A ferramenta não envia e-mails, não vende dados e não os usa para publicidade.

Compartilhamento

Quando o titular pede ao assistente Claude que leia ou procure mensagens, o conteúdo dessas mensagens é enviado ao Claude, serviço da Anthropic, para atender ao pedido. O tratamento pela Anthropic segue a política de privacidade da Anthropic. Nenhum outro terceiro recebe os dados.

Uso para IA

Os dados obtidos pelas APIs do Google Workspace não são usados para desenvolver, melhorar ou treinar modelos generalizados de inteligência artificial ou aprendizado de máquina.

Leitura humana

Ninguém além do titular lê os dados de e-mail acessados pela ferramenta.

Armazenamento e exclusão

A ferramenta roda no computador do titular. Não há servidor da ferramenta nem banco de dados externo. A autorização do Google fica no Gerenciador de Credenciais do Windows desse computador; anexos baixados ficam numa pasta local; um registro das ações (data, conta, ação e assunto, sem o conteúdo) fica numa pasta local. O titular pode apagar a autorização, os anexos e o registro a qualquer momento.

Uso de dados do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/linkedapps.
